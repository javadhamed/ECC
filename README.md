| نسخه / Edition | پلتفرم هدف / Target | توضیحات | لینک مستقیم به شاخه / Direct Branch |
| :--- | :--- | :--- | :--- |

## 🇮🇷 راهنمای استفاده سریع

### ۱. اگر از Google Antigravity استفاده می‌کنید:
به شاخه `antigravity` بروید یا با دستور زیر آن را کلون و نصب کنید:
```powershell
git clone -b antigravity https://github.com/javadhamed/ECC.git
cd ECC
.\install-antigravity.ps1
```

### ۲. اگر از OpenCode v2 استفاده می‌کنید:
به شاخه `opencode-v2` بروید:
```bash
git clone -b opencode-v2 https://github.com/javadhamed/ECC.git
```

## 🇬🇧 Quick Start Guide

### 1. For Google Antigravity Users:
Switch to the `antigravity` branch or clone it directly:
```powershell
git clone -b antigravity https://github.com/javadhamed/ECC.git
cd ECC
.\install-antigravity.ps1
```

### 2. For OpenCode v2 Users:
Switch to the `opencode-v2` branch:
```bash
git clone -b opencode-v2 https://github.com/javadhamed/ECC.git
```
